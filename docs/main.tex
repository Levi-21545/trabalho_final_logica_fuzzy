\begin{resumo}
A classificação de anomalias em testes de APIs REST enfrenta o desafio persistente do oráculo de teste, especificamente na distinção entre falhas de implementação e comportamentos esperados sob condições de estresse. Este trabalho apresenta a implementação de um Sistema de Inferência Fuzzy (FIS) integrado a uma ferramenta de fuzzing guiada por contrato para automatizar essa triagem de forma inteligente. O sistema utiliza três variáveis difusas — desvio de status code, tempo de resposta e tamanho do payload — para calcular um score de criticidade contínuo entre 0.0 e 1.0. Implementada em Python com a biblioteca scikit-fuzzy, a solução foi validada contra a aplicação vulnerável crAPI. Os resultados revelaram 207 anomalias, das quais apenas 42 foram classificadas como de alta severidade pelo motor fuzzy, demonstrando maior precisão e granularidade na priorização de falhas em relação a abordagens binárias tradicionais. A metodologia mostra-se promissora para integração em pipelines de CI/CD, otimizando o ciclo de desenvolvimento de software robusto.
\end{resumo}

\begin{abstract}
Anomaly classification in REST API testing faces the persistent challenge of the test oracle, specifically in distinguishing between implementation failures and expected behaviors under stress conditions. This paper presents the implementation of a Fuzzy Inference System (FIS) integrated with a contract-guided fuzzing tool to automate this triage intelligently. The system employs three fuzzy variables — status code deviation, response time, and payload size — to calculate a continuous criticality score between 0.0 and 1.0. Implemented in Python using the scikit-fuzzy library, the solution was validated against the crAPI vulnerable application. Results revealed 207 anomalies, of which only 42 were classified as high severity by the fuzzy engine, demonstrating greater precision and granularity in prioritizing failures compared to traditional binary approaches. The methodology proves promising for integration into CI/CD pipelines, optimizing the development cycle of robust software.
\end{abstract}
